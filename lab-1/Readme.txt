Lab 1 – Documentation
1. Variable and Identifier Practice

Aim: Declare variables and print their values and types.
Logic: Create variables for name, age, height, and student status. Use type() to display their data types.
Sample: Layak, 20, 5.11, True → str, int, float, bool

2. Greeting Program

Aim: Take name, age, and city and print a greeting.
Logic: Take three inputs and combine them using an f-string.
Sample: Layak, 20, Indore → Hello, my name is Layak, I am 20 years old and I live in Indore.

3. Arithmetic Operations

Aim: Perform basic arithmetic operations on two numbers.
Logic: Take two numbers and calculate sum, difference, product, quotient, and remainder.
Sample: 10, 3 → 13, 7, 30, 3.33, 1

4. Celsius to Fahrenheit

Aim: Convert Celsius temperature to Fahrenheit.
Logic: Take Celsius as input and apply F = (C × 9/5) + 32.
Sample: 25°C → 77°F

5. String Manipulation

Aim: Perform basic operations on a full name.
Logic: Use upper(), lower(), slicing, and len() on the input string.
Sample: Layak Rathore → LAYAK RATHORE, layak rathore, erohtar kayal, 13

6. Escape Sequence Practice

Aim: Create a neatly formatted receipt.
Logic: Use \t for spacing and \n for new lines.
Sample: Pen ₹20, Notebook ₹50, Pencil ₹10 → Total ₹80
